# Visual library: tutorials and onboarding

Fifty-nine references on teaching a new player: screenshots of Roblox games that guide well, guidance-device builds, real onboarding funnels with their numbers, developer threads on what failed, and the best outside writing and talks on teaching through play. The method that uses them is `references/tutorial-and-onboarding.md`.

How to use this file: pick the sub-aspect you are building (a pointer, a hint, a funnel read), open two or three entries, and copy the observation in "Look at it for", not the artwork. Image rows give the page and the direct image URL so the image can be downloaded and viewed again. These are references to study, not assets: third-party images, code and text stay third-party.

Evidence: `viewed` = image downloaded and looked at; `read` = page, thread, paper or source code read; `oembed` = video existence, title and channel verified, not watched (what it covers is taken from its title or from the page that cites it); `search` = not opened. `[VS]` = depends on an API or dashboard that may change. Accessed 2026-11-11. No hit game was played for this file: the game screenshots are the ones Roblox chose for its own docs.
