# Animation reference library

What this is: 57 checked references for character and creature animation in a Roblox game: craft breakdowns, frame-data thinking, Roblox tutorials and critique threads, reference footage, rigs and tools. The rules these references support live in `references/animation-and-rigs.md` (§4 holds the recipes, tells table and rubric).

How to use this file:
- Pick the sub-aspect you are working on, open two or three rows, and write down what you will copy as a number (frames, degrees, pose count) before you animate.
- Evidence: `viewed` = the image or a frame contact sheet of the clip was looked at; `read` = the page or thread was read; `oembed` = the video exists with that title and creator, it was not watched, and the note comes from its title or the page that led to it; `search` = seen only in search results, not opened.
- These are references to study, not assets to copy: every third-party image, clip and rig stays its owner's. Tool rows state the licence that was read, or say "licence not verified". Accessed 2026-11-11.

Image host prefixes used below: `DF` = `https://devforum-uploads.s3.dualstack.us-east-2.amazonaws.com/uploads`, `DOCS` = `https://prod.docsiteassets.roblox.com/assets/animation`, `GD` = `https://eu-images.contentstack.com/v3/assets/blt740a130ae3c5d529`, `LV` = `https://cdn.80.lv/api/upload/content`.
