# Start Here

A playbook for designing and building great Roblox games: guides, genre playbooks, market research, agent skills, templates, reference sheets and tools, sorted into numbered folders and linked to each other.

## Pick your door

- **Build a game from scratch:** [[How to Build a Great Roblox Game]]
- **Make an existing game better:** [[Audit an Existing Game]] with [[Skill - Level Up]]
- **Solve one problem:** [[Task Router]] (one row per job) or [[Skills Overview]] (which skill fits)
- **See everything:** [[Vault Map]]
- **Rules that override everything:** [[House Rules]]
- **Look up a term:** [[Glossary]]

## For AI agents

Read `AGENTS.md` at the top of this folder. In short: use the Task Router, or run `python "99 Meta/search_vault.py" "words"`, or read `99 Meta/vault-index.json`; open only the heading you need; guides beat the archive; check platform facts at https://create.roblox.com/docs.

## What is where

- Folders `01`–`15`: the guides, by discipline.
- `16 Visual Library`: checked examples to study (linked, not bundled).
- `17 Reference Sheets`: 22 original diagrams. See [[Reference Sheets Gallery]].
- `18 Skills`: the 14 agent skills, each with an "At a glance" box.
- `19 Templates`: documents to fill in at each step.
- `20 Scripts and Tools`: Blender and Studio helpers.
- `90 Archive - Knowledge Base`: the original 90,000-word source text, split by section ([[Knowledge Base Archive - Index]]).
- `99 Meta`: search index, search script, [[Path Map]], [[Sources and Credits]].
