How to use this sheet

Read A and B for how far apart two answers to one brief can be: different light, value key, material and motif, same rigour. The blank is what you fill. The genre table in art-direction §4 holds more directions.

Why one page

Every line is a number or a side-by-side a reviewer can check. A page fits beside the viewport, so three artists (or three agents) build one world instead of three.

Where the numbers come from

Bevels from the viewing-distance tables; value bands from the craft guide; light from the lighting guide's rows with the deviation step; defaults sampled from env rows 63–64.
