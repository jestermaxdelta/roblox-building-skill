House rule 3 on this screen

A timer only for a real state (a boost that is running, an event end that does not move). A discount only against a price that was really charged. No restarting countdown, no hidden or delayed close. Label paid things as paid: the Robux icon, utf8.char(0xE002), before every Robux price. Paid random items show full odds from the config the server rolls from.
