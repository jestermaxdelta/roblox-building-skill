Colour script for a day cycle: interpolate every field, not only ClockTime (swatches are the guide's RGB values)

Night is shown by hue, lower saturation and lit windows, not by darkness: keep night ambient tinted and well above black (the Night column runs 60–140 per channel) so silhouettes read at 50 studs. Most games should pick one hour and tune it; add a cycle only when night changes play.
