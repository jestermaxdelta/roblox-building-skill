How to count

Count groups, not instances: one menu column is one element. Cap 5–7 on phones; more than 8 persistent elements is an audit finding.

Squint test

At phone size over real gameplay, the primary action and the primary currency are found in under 1 s. In A and B nothing wins.

Density is allowed

Hit simulators run dense HUDs. Keep the cap by grouping, hide secondary buttons behind More, badge only what is claimable now.
